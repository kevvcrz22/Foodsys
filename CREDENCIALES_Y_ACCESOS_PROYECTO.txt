3. BASE DE DATOS RELACIONAL (MYSQL)
--------------------------------------------------------------------------------
- Motor: MySQL 8.0+ / MariaDB 10.4+
- Nombre de la Base de Datos: foodsys
- Codificacion (Charset): utf8mb4 / Collation: utf8mb4_unicode_ci
- Archivo SQL Canonico Maestro: Node/Database/foodsys_canonical_schema.sql
  (Contiene la creacion completa de tablas, llaves foraneas, vistas, procedimientos
   y datos iniciales de roles, comedores, jornadas y configuraciones).
- Parametros de Conexion Local por Defecto (Node/.env):
  * DB_HOST=localhost (o 127.0.0.1)
  * DB_PORT=3306
  * DB_NAME=foodsys
  * DB_USER=root
  * DB_PASS= (vacio por defecto en XAMPP o configurar segun servidor local)
- Parametros de Produccion (Plantilla en Node/.env.example):
  * DB_HOST=127.0.0.1
  * DB_PORT=3306
  * DB_NAME=foodsys
  * DB_USER=foodsys_user
  * DB_PASS=<clave_segura_servidor>

5. PUESTA EN MARCHA LOCAL Y EN RED INTERNA DEL SENA
--------------------------------------------------------------------------------
Para ejecutar el aplicativo de forma gratuita y autonoma en cualquier computador
del Centro Agropecuario La Granja:

1. Ejecucion Automatica en un solo clic:
   - Hacer doble clic sobre el archivo: INICIAR_FOODSYS_LOCAL.bat
   - Este script arranca de forma simultanea y silenciosa:
     * Backend API en: http://localhost:8000
     * Frontend Web en: http://localhost:5173

2. Habilitar Acceso en Red Local (Casino, Torniquetes y Oficinas):
   - Hacer clic derecho y "Ejecutar como Administrador" en:
     HABILITAR_ACCESO_RED_LOCAL.bat
   - Cualquier dispositivo conectado a la misma red Wi-Fi o cableada del SENA podra
     acceder usando la direccion IP local del equipo servidor, por ejemplo:
     http://192.168.1.50:5173

3. Detener Servicios:
   - Hacer doble clic en: DETENER_FOODSYS.vbs


6. DETENCION DEFINITIVA DE COSTOS EN HETZNER CLOUD (PASO A PASO)
--------------------------------------------------------------------------------
Dado que Hetzner Cloud factura por horas de reserva del servidor mientras exista,
para eliminar el servidor y retirar la tarjeta de credito sin costo adicional:

Paso 1: Entrar a la consola de Hetzner Cloud:
        https://console.hetzner.cloud/

Paso 2: Seleccionar el Proyecto donde se encuentra el servidor Foodsys.

Paso 3: En el menu izquierdo, hacer clic en "Servers".

Paso 4: Hacer clic en el servidor activo y dirigirse a "Actions" (o "Delete").

Paso 5: Seleccionar "Delete Server", escribir el nombre del servidor para
        confirmar y presionar el boton rojo de eliminacion.
        *A partir de este instante cesa todo cobro de Hetzner.*

Paso 6: Ir a https://accounts.hetzner.com/ -> "Billing" -> "Invoices" para
        cancelar la ultima factura correspondiente a los dias utilizados.

Paso 7: Ir a "Payment Methods" y eliminar la tarjeta de credito personal vinculada.
